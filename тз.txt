Требования:

PostgreSQL 11.1
Python 3.7.3
Django 1.11
Bootstrap 5

Raw sql запросы (не использовать ORM)
Обмен данными в формате JSON
интерфейс пользователя на чистом JavaScript + Bootstrap 5
разворачивания инфраструктуры поддерживающих серверов не требуется
работа без внешних подключений к ресурсам в интернете

Функционал:
Реализовать базу данных и приложение django.
Реализовать список должностей: "должность" и "категория" (выбор вариантов: руководитель, специалист, служащий, рабочий).
Добавление, изменение, удаление должностей.
Список сотрудников: ФИО, пол, возраст, должность, категория.
Добавление, удаление сотрудника.
Личная карточка сотрудника. Редактирование: ФИО, пол, возраст. Выбор должности из списка.
